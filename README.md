# grisha-gu/homebrew-tap

Homebrew casks for [AgentLight](https://github.com/grisha-gu/agentlight).

```bash
brew install grisha-gu/tap/agentlight
agentlight install-daemon && agentlight install-hooks
```

`Casks/agentlight.rb` is updated by the AgentLight release workflow; edit
[packaging/homebrew/agentlight.rb](https://github.com/grisha-gu/agentlight/blob/main/packaging/homebrew/agentlight.rb) instead.
